## Возможности

**Модули:**

| Модуль | Предмет | Тема |
| :--- | :--- | :--- |
| **Sin_cos** | Математика | Тригонометрия, единичная окружность |
| **Functions** | Математика | Преобразование 10 видов графиков, режим сравнения двух функций |
| **Oscillator** | Физика | Затухающие механические колебания |
| **Incline** | Физика | Брус на наклонной плоскости, силы, трение |
| **Curvature** | Физика | Криволинейное движение, МЦС, центр кривизны |

**Интерфейс:**

- **Боковая панель управления:** все слайдеры, переключатели и настройки вынесены в левую выезжающую панель (как в Desmos), что дает максимум места для графиков. Состояние панели сохраняется.
- **Умный Zoom и Pan:** масштабирование колёсиком мыши и панорамирование работают во всех модулях.
- **Редактор границ осей:** ручной ввод `Xmin`, `Xmax`, `Ymin`, `Ymax` с автоматическим сохранением пропорций (окружность всегда остается круглой).
- Тёмная и светлая темы, 3 размера текста.
- Единая панель расчётов во всех модулях.
- Глобальное управление анимацией (пуск, пауза, шаг, скорость).
- Экспорт кадра в PNG.
- Автообновление через GitHub Releases.

**Горячие клавиши:**

| Клавиша | Действие |
| :--- | :--- |
| `Ctrl+H` | Главная страница |
| `Ctrl+P` | Показать / скрыть боковую панель |
| `Ctrl+I` | Показать / скрыть панель расчётов |
| `Ctrl+S` | Сохранить кадр в PNG |
| `Ctrl+0` | Сбросить зум и границы осей |
| `Ctrl+1…9` | Быстрый переход к модулю |
| `Space` | Пуск / пауза (в анимации) |
| `A` / `D` | Шаг назад / вперёд |
| `R` | Сброс параметров |
| `1…4` | Переключить векторы / элементы |
