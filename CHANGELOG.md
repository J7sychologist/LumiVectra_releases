# Changelog

Все значимые изменения проекта LumiVectra.

## [0.3.2] - 2026-11-03

### Added

- **Боковая панель управления:** все слайдеры, флажки и выпадающие списки перенесены из верхней части экрана в левую выезжающую панель (как в Desmos). Графики занимают всё освободившееся место.
- **Управление панелью из тулбара:** кнопка «Показать/скрыть настройки» в главном меню (горячая клавиша `Ctrl+P`). Состояние панели (ширина и видимость) сохраняется в `QSettings` и синхронизируется при переключении модулей.
- **Zoom и Pan во всех модулях:** масштабирование колёсиком мыши и панорамирование ЛКМ теперь доступны в «Наклонной плоскости» и «Криволинейном движении».
- **Редактор границ осей (Desmos-style):** добавлены поля ручного ввода `Xmin`, `Xmax`, `Ymin`, `Ymax` с умным сохранением пропорций. Окружность всегда остаётся круглой при изменении размера окна.
- **`update_env.bat`:** новый скрипт для автоматического обновления `pip` и всех зависимостей в виртуальном окружении.

### Changed

- **Унификация подписей слайдеров:** убраны лишние тире (например, `A, м` вместо `A — A:`). Полные названия параметров вынесены во всплывающие подсказки (`setToolTip`).
- **Nuitka обновлена до `4.3.3`:** исправлен баг с кэшированием сборки и улучшена совместимость с PySide6.
- **Рефакторинг базовых классов:** метод `_zoom_pan_axes` перенесен в общий миксин `_PlotHelpersMixin` для корректной работы зума в составных модулях.
- **Единый стиль настроек:** все флажки и переключатели сгруппированы в логические блоки («Настройки», «Векторы», «Опции»).
- **`README.md` и файлы лицензий:** обновлены с учетом текущего правообладателя (СФУ) и нового функционала.

### Fixed

- **Светлая тема:** исправлен чёрный фон и невидимый текст в выпадающих списках (`QComboBox`), флажках (`QCheckBox`) и полях ввода (`QDoubleSpinBox`).
- **Стрелки спинбоксов:** заменены дефолтные квадраты на аккуратные SVG/PNG-стрелки, окрашиваемые в цвет темы.
- **Зависание зума в Functions:** исправлена ошибка `AttributeError`, из-за которой график не перерисовывался при прокрутке колесика, а поля `Xmin/Xmax` не обновлялись.
- **Краш при смене режимов:** исправлен `AttributeError: 'CompareModePage' object has no attribute 'btn_toggle_panel'` в «Осцилляторе» и «Преобразовании функций».
- **`installer.iss`:** исправлена фатальная ошибка сборки из-за дублирования директивы `AppPublisher`.

### Note

- Для обновления на версию 0.3.2 рекомендуется сначала запустить `update_env.bat`, затем `build.bat`.

## [0.3.1] - 2026-10-06

### Added

- **Новый модуль «Преобразование функций»** (математика, 9–11):
  прямая, парабола, кубическая, гипербола, корень,
  показательная, логарифмическая, синусоида, модуль,
  окружность. Живое редактирование коэффициентов,
  настраиваемые диапазоны, Xlim/Ylim, особые точки,
  формула на графике, зум колёсиком и панорамирование мышью.
- **Splash screen** при запуске: анимированный логотип,
  тёмный фон, футер с копирайтом. Маскирует время загрузки
  главного окна.
- **Логотипы LumiVectra** — кириллица и латиница,
  для тёмной и светлой темы, в форматах PNG и SVG.
  Знак V (icon_mono.svg) — для favicon и мелких мест.
- **Зум колёсиком и панорамирование мышью** в модулях
  Functions и Oscillator. Колесо — масштаб вокруг курсора,
  ЛКМ + движение — сдвиг графика. Ctrl+0 — сброс вида.
- **Юнит-тесты физических моделей**:
  test_oscillator_model (14), test_incline_model (17),
  test_curvature_model (20), test_sin_cos_model (8),
  test_function_model (11). Итого 70 новых тестов
  поверх 43 инфраструктурных.
- **Русские названия модулей** (MODULE_UI_TITLE):
  «Синус и косинус», «Осциллятор», «Наклонная плоскость»,
  «Криволинейное движение», «Преобразование функций».
- **Методички модулей** в docs/modules/: sin_cos, oscillator,
  incline, curvature, functions.
- **docs/architecture.md** — описание платформы для
  патентной заявки (назначение, аудитория, архитектура,
  технические решения, отличия от аналогов).

### Changed

- **Унификация модулей через базовые классы:**
  `BasePlotModule`, `BaseAnimatedPlotModule`, `BasePlotPage`.
  Модули сократились на 25–40% кода.
- **`ui/param_slider.py`** — общий класс слайдера для всех
  модулей. Опции `range_edit` (поля границ диапазона),
  `compact` (компактная подпись «A = 1.00»).
- **`ui/plot_helpers.py`** — общие помощники:
  `setup_shortcuts`, `draw_arrow`, `style_time_axes`,
  `save_figure_dialog`, `save_canvases_dialog`,
  `ZoomPanController`.
- **Темы сокращены до двух** — тёмная и светлая. Палитра
  согласована с логотипом: фон тёмной `#0a1628`, акцент
  UI `#0099cc`. Графики сохранили более яркий `#00d4ff`.
  Автоматическая миграция старых тем из QSettings:
  dark-blue / dark-green → dark, light-warm → light.
- **Окно «О программе»** переписано под QDialog с логотипом
  и без перечисления модулей.
- **Inno Setup установщик:** иконка V в правом верхнем углу
  каждой страницы мастера (WizardSmallImageFile).

### Fixed

- **Oscillator:** коэффициент жёсткости `k = m·ω₀²` вместо
  `m·ω²`. Полная энергия E(t) теперь монотонно убывает при
  β > 0 (раньше содержала знакопеременное слагаемое).
- **Sin_cos:** выравнивание меток 1 и −1 на окружностях
  и графиках; сдвиг подписей X, Y; метки осей ближе к осям.
- **Incline:** отступ подписей векторов от стрелок.
- **Email в «О программе»** виден на тёмных темах (акцентный
  цвет вместо стандартного тёмно-фиолетового).
- **Splash:** пропорции GIF сохраняются, полный цикл
  анимации доигрывает до конца, DPI-масштабирование
  не срезает края.

### Note

- При переходе с 0.3.0 на 0.3.1 обновление устанавливается
  поверх старой версии в `%LOCALAPPDATA%\Programs\LumiVectra\`.
  Настройки пользователя сохраняются.

## [0.3.0] - 2026-10-05

### Added

- Список сторонних компонентов и их лицензий (`NOTICE`).

- QSettings: `Sizasko/LumiVectra`.
- Публичный и приватный репозитории переименованы.

### Fixed

- Корректное определение лаунчера `LumiVectra.exe` в Nuitka-сборке
  (чинит автообновление).
- Исключены `matplotlib.tests` и `matplotlib.testing` из сборки.

### Note

- При переходе с FMS_SUPPLY 0.2.9 на LumiVectra 0.3.0 требуется
  ручная установка нового установщика. Автообновление со старой
  версии не сработает: сменился репозиторий и имя продукта.

## Как читать CHANGELOG

- **Added** — новая функциональность
- **Changed** — изменения в существующем поведении
- **Deprecated** — то, что будет удалено в будущем
- **Removed** — то, что удалено сейчас
- **Fixed** — исправления ошибок
- **Security** — уязвимости (не используется в этом проекте)

## Как добавить запись

1. Откройте `CHANGELOG.md`.
2. Вставьте новую секцию сразу под строкой `## [Unreleased]` (если она есть) или в самом верху — перед предыдущей версией.
3. Используйте формат `## [X.Y.Z] - ГГГГ-ММ-ДД`.
4. Группируйте изменения по категориям (Added / Changed / Fixed / Removed).
5. Пишите в прошедшем времени: «Добавлена», «Изменено», «Исправлено».
